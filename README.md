# Веб-приложение для учёта финансов с аналитикой

Курсовая работа. Стек: **Python 3 + Flask + SQLAlchemy + SQLite + Chart.js + Bootstrap 5**.

## Возможности

- Регистрация и вход пользователей (пароли хешируются)
- CRUD транзакций (доходы / расходы)
- Управление категориями
- Фильтрация транзакций по типу, категории и дате
- Дашборд с ключевыми показателями
- Круговая диаграмма структуры расходов
- Столбчатая диаграмма динамики за 6 месяцев
- REST-подобные JSON-эндпоинты для аналитики

## Требования

- Python 3.10+
- pip

## Установка и запуск

```bash
# 1. Перейти в папку проекта
cd finance_app

# 2. Создать виртуальное окружение (рекомендуется)
python -m venv venv

# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить приложение
python app.py
